1Template & Map — two layout directions

Same features as ui.rs, rearranged at 1280×800. Direction A (1a 1c) is a workbench: a fixed mode rail, the canvas in the middle, an inspector on the right; settings collapse to one-line summaries. Direction B (1b 1d) keeps today's top tabs and splits each page into ordered steps or a single control column. Nothing scrolls the whole window; only panels scroll. Each maps to SidePanel / TopBottomPanel / CentralPanel + CollapsingHeader. Faction red/teal are kept as data colors only.
