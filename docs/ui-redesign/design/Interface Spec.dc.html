04

Map tool safety

  • One tool is active at a time. It is filled in the accent color, the cursor matches it, and a banner on the map names it and says how to finish.
  • Esc cancels a line in progress and returns to Select.
  • Place objective tools are one-shot: one click places one objective, then the tool returns to Select. Hold Shift to place several.
  • Right-drag pans in every tool.
  • Leaving the Map tab returns to Select.
  • The status bar repeats the active tool's hint.
SALIENTClick along the front · right-click to finish · Esc to cancel
05

Side markers face opposite directions

Keep the existing assets/Eastern*.svg and assets/Nato*.svg icons. DPRK icons point south, toward the front from the north; NATO icons point north. Direction tells the sides apart without color, so red/teal becomes a second cue. Lists, legends and the map all use the same orientation.

Backlog · future release

Define a minimum usable group for each tab

Item 2 (a readiness check next to Generate) is deferred. It first needs a definition of the smallest output each tab should allow. The code already enforces some of these rules and they are a starting point:

  • Exclusive Activation: each plan has at least one start checkzone and an end timer.
  • Army Generator: each template has at least one Zone In selected.
  • Template: flights with wingmen must use Activate.
  • Open: Template, Fighter Pack, Airfield and Map have no written minimum yet.
