## Wiring for one entry

The clock still allocates 11 MCUs per entry, or 10 for the last waterfall position. `RANDOM ON` is repurposed and renamed `AVAILABLE ON`. The links below are production links; the frozen 2L probe explicitly selects its old wiring.

| Node | Targets / effect | Switched by |
| --- | --- | --- |
| `RANDOM` | Pulses `AVAILABLE` after its unchanged weighted roll and waterfall delay | Nothing |
| `AVAILABLE` | Zero-second D11 relay to `OUT`, then `CLOSE` if present | On: `AVAILABLE ON`; off: `EXCLUDE`, the area's `AREA OUT`, `EXHAUSTED` |
| `AVAILABLE ON` | Activates `AVAILABLE`; pulsed by `SLOT OPEN` | Off permanently: `EXHAUSTED` |
| `LAST` | Pulses `EXCLUDE` when `NO REPEAT` reaches it at slot +0.1 s | Initially off; on: `LAST SET`; off: `LAST CLEAR` at `DRAW` |
| `EXCLUDE` | Deactivates `AVAILABLE` | Nothing |
| `LAST SET` | Activates `LAST`; pulsed by an actual copy `START` | Nothing |
| `OUT` | Pulses `HOT` and `COLD` | On: `ReOpen Outputs` each draw; off: earlier entries' `CLOSE` |
| `CLOSE` (absent on last entry) | Deactivates later entries' `OUT` relays | Nothing |
| `HOT` | Pulses `GO` | Initially off; the area's threshold `HOT ON` / `HOT OFF` |
| `COLD` | Pulses the area's `AREA OUT` | The area's threshold `COLD ON` / `COLD OFF` |
| `GO` | Pulses `WIN`, then copy pointers in reverse run order; the real budget gates decide whether `START` occurs | Off permanently: `EXHAUSTED` |

The area's `AREA OUT` deactivates every clock entry's `AVAILABLE` in that area. `EXHAUSTED` deactivates `AVAILABLE`, `AVAILABLE ON`, and `GO` (plus the existing zone targets for a `Both` entry). Disabling the activator prevents later slots from reopening an exhausted gate. A running `RANDOM` expires normally into a closed gate; it cannot reach either `OUT` or `CLOSE`. `ATTEMPT END` / `REROLL` retain 0044's wiring.

Trace selection now includes slot/draw/attempt decisions, `LAST`, and `RANDOM`, `AVAILABLE`, `OUT`, `HOT`, `COLD`, `GO`, so timer expiry can be distinguished from a gate pass and a waterfall winner. This uses the existing trace instrumentation, including its switch handling.
